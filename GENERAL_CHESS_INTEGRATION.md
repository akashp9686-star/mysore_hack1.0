# General Concepts + Chess Integration

This is the existing HackMysore 1.0 Personalized Learning Platform with the previously reserved General Concepts area activated.

## Active General Concepts
- Communication Skills
- Spell Talk
- Brainstorm
- Chess Learning

General Concepts activities support Grades 5–9 with saved local progress, retries, feedback, and coin rewards.

## Chess
- 75 levels: Beginner 1–25, Intermediate 1–25, Advanced 1–25.
- The Chess board is rendered in the browser using chess.js.
- Problems are loaded from the bundled `frontend/chess/data/problems.json` file.
- The active Chess problem page no longer depends on `/api/chess/problems`, so the board works as part of this website package.

The existing Class 8 Mathematics, teacher authoring, misconception diagnostics, adaptive engine, and backend are retained.
